Install nnU-Net as described on their website.
https://github.com/MIC-DKFZ/nnUNet/blob/master/documentation/installation_instructions.md

## Dependencies

- `requirements.txt` — core, also shipped to doctors' machines via aortic-seg-infer.
- `requirements-full.txt` — the `[full]` extra (training, analysis, plots).
- `constraints.txt` — exact versions shared by the developer `.venv` of this
  project and `../aortic-seg-infer`. Generated by `tools/sync_envs.py`.

Setting up `.venv`:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -e ".[full]" -c constraints.txt
.venv\Scripts\python -m pip install -e ..\morpho-gcn -c constraints.txt
```

After upgrading or adding a package in either project:

```powershell
.venv\Scripts\python tools\sync_envs.py update   # newer version wins, == pins in requirements.txt win over all
.venv\Scripts\python tools\sync_envs.py apply    # bring both .venv to constraints.txt
.venv\Scripts\python tools\sync_envs.py          # check
```

Then commit `constraints.txt`.
